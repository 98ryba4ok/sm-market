## 🤔 Сомнения и вопросы

### 1. Миграция существующих данных
**Вопрос**: Как обработать существующие товары и категории?

**Текущая ситуация**:
- У существующих товаров `room = NULL`
- У существующих категорий `rooms = []` (пустой список)

**Варианты**:
1. Создать data migration для заполнения помещений
2. Заполнить вручную через админ-панель
3. Оставить как есть (товары без помещения будут показываться во всех)

**Рекомендация**: Создать помещения через админку и назначить их категориям/товарам

### 2. Логика отображения товаров
**Вопрос**: Как показывать товары без привязки к помещению?

**Варианты**:
1. Не показывать товары без `room` в фильтрах по помещениям
2. Показывать во всех помещениях
3. Создать специальное помещение "Общее" или "Без категории"

**Рекомендация**: Вариант 1 - не показывать в фильтрах, но показывать в общем каталоге

### 3. URL структура каталога
**Вопрос**: Как должны выглядеть URL в новой структуре?

**Старая структура**:
- `/catalog` - все товары
- `/catalog?category=slug` - товары категории

**Новая структура (варианты)**:
- Вариант A: `/catalog?room=slug&category=slug`
- Вариант B: `/catalog/room-slug/category-slug`
- Вариант C: `/catalog?room=slug` + `/catalog?category=slug`

**Рекомендация**: Вариант A (query параметры) - проще в реализации

### 4. Обратная совместимость
**Вопрос**: Нужно ли поддерживать старые URL с parent категориями?

**Проблема**: Могут быть внешние ссылки на старые URL

**Рекомендация**: Добавить редирект со старых URL на новые
